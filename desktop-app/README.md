# 🖥️ Smart POS - Desktop App & Installer (.exe)

โฟลเดอร์สำหรับจัดการโปรแกรมติดตั้ง Windows (.exe) ของระบบ Smart POS โดยเฉพาะ แยกเป็นสัดส่วนเพื่อไม่ให้ปะปนกับโค้ดหลัก

---

## 📂 รายละเอียดไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่การทำงาน |
| :--- | :--- |
| **`run-desktop.bat`** | ดับเบิลคลิกเพื่อ **ทดสอบเปิดโปรแกรม Desktop บนคอมพิวเตอร์** ทันทีในหน้าต่างเดี่ยว |
| **`build-installer.bat`** | ดับเบิลคลิกเพื่อ **สร้างไฟล์ติดตั้ง `.exe`** (รอระบบสร้างเสร็จ จะเปิดโฟลเดอร์ `release/` ขึ้นมาให้ทันที) |
| **`release/`** | โฟลเดอร์เก็บไฟล์ตัวติดตั้งหลังจากสั่งบิลด์เสร็จแล้ว |
| **`main.cjs`** | สคริปต์ควบคุมหน้าต่างโปรแกรม Electron และจัดการสตาร์ทเซิร์ฟเวอร์ในตัว |
| **`package.json`** | การตั้งค่า Electron และตัวแพ็กเกจ Electron Builder |

---

## 🚀 วิธีการใช้งาน

### 1. วิธีเปิดทดสอบโปรแกรม Desktop:
* เพียงดับเบิลคลิกไฟล์ **`run-desktop.bat`**
* โปรแกรมจะเปิดหน้าต่างโปรแกรม POS ขนาดใหญ่ สวยงาม ไม่มีแถบ URL ทันที

### 2. วิธีสร้างไฟล์ติดตั้ง `.exe` เพื่อนำไปลงเครื่องอื่น:
* ดับเบิลคลิกไฟล์ **`build-installer.bat`**
* ระบบจะทำการคอมไพล์และสร้างไฟล์ติดตั้งให้ในโฟลเดอร์ **`release/`**:
  * **`Smart POS Setup 1.0.0.exe`** ➡️ นำไฟล์นี้ไปลงเครื่อง PC หรือ Laptop เครื่องอื่นได้ทันที (มีขั้นตอน Next ➡️ Next ติดตั้งลง Desktop)
  * **`Smart POS 1.0.0.exe` (Portable)** ➡️ ก๊อปปี้ใส่ Flash Drive ไปเปิดใช้งานได้เลยโดยไม่ต้องติดตั้ง
